# Trademark policy

The code and specification are open. The names are protected so that users can tell what they are getting. For what each name means, see [NAMING.md](NAMING.md).

## The marks

| Mark | Owner | What it covers | Status |
|---|---|---|---|
| **OpenChart** | CareCircle Connect Inc. | The open-source project, repo, website and community | Used as a trademark; registration not yet completed |
| **OpenChart Certified** (certification mark and badge) | CareCircle Connect Inc. | Products that pass the OpenChart certification programme | Not yet in use; the programme is not yet open |
| **CareCircle**, **CareCircle Link** | CareCircle Connect Inc. | CareCircle's company name and its hosted network and apps built on OpenChart | Used as trademarks; registration not yet completed |
| **PDRE** / **Patient-Directed Record Exchange** | Specification name, stewarded by CareCircle Connect Inc. for the community, with a commitment to transfer it to the neutral governing body | The technical protocol specification | Descriptive specification name |

Names may change if a conflict comes to light. If that happens, we'll publish the new name and a transition period.

## What you can do without asking

- Say your product **"implements PDRE 0.1"** (or the version you implement), when that is true.
- Say your product **"works with OpenChart"**, when that is true and factual.
- Use the names to refer to this project in articles, talks, blog posts and teaching.
- Fork the code and the specification under their licences.

## What needs permission or certification

- Using **"OpenChart Certified"** or the badge. Only products that pass the certification programme (once open) and hold a current listing may use it.
- Using "OpenChart", "CareCircle" or "CareCircle Link" as part of your product, company, domain or app name.
- Using the logos.

## Forks

Forks are welcome. A fork must use a different name, must not call itself OpenChart, and a modified specification must not suggest it is PDRE or endorsed by the project.
